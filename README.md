Write the funniest one-line warning label for a time machine in 120 characters or fewer. Free entry, $2 to the funniest line, judged in private rounds. A Python program writes the label to `/output/entry.txt`: a straight-faced safety notice whose punchline lands on the last few words — the real hazard of time travel, meeting your own past self, turned into the joke.

> WARNING: Do not wave at your past self. He is armed, bitter, and already blames you for this trip.

## Run it

```sh
python3 main.py
```
