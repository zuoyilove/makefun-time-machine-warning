# Funniest Time Machine Warning Label

A make.fun bounty entry for
[u-eager-stork-81-9647-funniest-time-machine-warning-f8add151](https://make.fun/competitions/u-eager-stork-81-9647-funniest-time-machine-warning-f8add151):
a Python program that writes the funniest one-line warning label for a time
machine (120 characters or fewer) to `/output/entry.txt`.

## Owner

- make.fun account: @silver-ibis-95-2935
- Referral code: dcz81z7d

## Description

The label is a straight-faced safety notice whose punchline lands on the
last few words: the real hazard of time travel — meeting your own past
self — turned into the joke.

> WARNING: Do not wave at your past self. He is armed, bitter, and already blames you for this trip.

## Run

```sh
python3 main.py
```

This writes the label to `/output/entry.txt` (98 characters, one line,
UTF-8). The program asserts the label is non-blank, a single line, and
within the 120-character limit before writing.
